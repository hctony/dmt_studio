# LOT 테스트 기록과 스마트 입력

## 현장 테스트 방법

1. 원래 사용할 작업 화면에서 왼쪽 **LOT 테스트 기록 · 추천**을 엽니다.
2. 모델과 LOT를 입력하고 **이 LOT 기록 시작**을 누릅니다. 현재 화면의 모델·LOT에 적용됩니다.
3. 평소대로 경로를 선택하고 분석·내보내기를 실행합니다. 다른 화면에서도 같은 모델·LOT를 사용하세요.
4. 기록 화면을 다시 열고 메모를 작성한 뒤 **테스트 성공 확인** 또는 **실패로 기록 종료**를 누릅니다. 성공은 사용자가 실제 결과를 확인했다는 뜻입니다.
5. 같은 모델에서 서로 다른 LOT 3개 정도를 테스트합니다. **분석용 로그 JSON 내보내기**로 파일을 저장하여 이후 분석에 전달할 수 있습니다.
6. 다음 LOT의 모델·LOT를 넣고 **이 모델·LOT의 추천 보기**를 누르면 경로·입력값과 근거를 표시합니다. 선택한 추천을 한 번에 입력할 수 있습니다.

## 추천 규칙

- 같은 모델의 성공 확인 기록만 사용합니다. 실패·중단 기록도 로그에 남지만 학습에는 사용하지 않습니다.
- 같은 LOT를 반복 실행해도 최근 성공 기록 하나만 투표합니다. 추천 대상 LOT 자체의 기록은 근거에서 제외합니다.
- LOT 경계가 확인되는 경로 문자열을 `{LOT}` 템플릿으로 바꿔 비교합니다. 반복되는 고정 경로, 설비 IP 범위, Strip당 Unit 수, X-out 한도 등의 입력도 비교합니다.
- 필드별로 서로 다른 3개 이상 LOT에서 모두 일치한 규칙만 확실한 추천입니다. 일부가 충돌하면 확인 필요로 표시하고, 최다 후보가 동률이면 추천하지 않습니다.
- 확실한 추천으로 빈 칸 자동입력은 선택 옵션이며, 새 LOT 기록을 시작할 때 적용됩니다. 기존 값 교체는 사용자가 별도로 선택합니다. 다른 모델·LOT가 입력된 화면은 건너뜁니다.
- 자동입력은 입력칸만 변경합니다. 분석 실행, LM 파일 변경, 다운로드 등의 버튼은 자동으로 누르지 않습니다.
- 경로 존재·파일 최신 여부를 확인한 추천은 아닙니다. 경로 규칙을 예측하며 실제 파일 확인은 기존 실행 흐름에서 수행합니다.

## 기록과 내보내기

사용자 설정 폴더의 `workflow-history` 아래에 LOT별 JSON을 원자적으로 저장합니다. 버전, 시작/종료 시각, 모델·LOT, 입력 변경, 버튼 작업, 소요 시간, 메시지, 표 크기와 결과 로그 요약, 현장 메모를 포함합니다. 백그라운드 작업 종료는 `workers_idle` 이벤트로 기록하며 자동으로 성공 판정을 내리지 않습니다.

한 LOT당 최근 1,000개 이벤트를 유지하며 잘린 이벤트 수를 기록합니다. 프로그램이 중간에 종료된 LOT는 다음 시작 시 중단으로 분류합니다. 원본 분석 파일 전체와 `.env`는 수집하지 않으며 알려진 비밀번호·토큰 값은 기록에서 제거합니다. 내보내기에는 현장 경로와 LOT 정보가 포함됩니다. 외부 업로드는 자동으로 하지 않습니다.

한국어/대만 번체로 동일한 흐름을 제공합니다. 추천은 로컬 규칙 기반이며 외부 AI 서비스나 API 키가 필요하지 않습니다.
