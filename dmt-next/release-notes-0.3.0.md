# DMT Analysis Studio 0.3.0

기존 10개 탭에 LOT 테스트 기록과 스마트 입력 기능을 추가했습니다.

- 모델·LOT별 기록 시작, 성공/실패 확인, 메모와 로그 JSON 내보내기.
- 선택 경로·입력 변경·작업 시간·결과 요약 기록. 중단한 세션 복구 및 학습 제외.
- 같은 모델의 서로 다른 성공 LOT 3개 이상에서 반복된 경로·입력 규칙 추천.
- LOT명 치환 경로, 고정 경로, 설비 IP와 주요 수치의 근거 표시 및 선택 자동입력.
- 확실한 추천으로 빈 칸 자동입력 옵션. 기존 값 교체는 별도 선택하며 작업 실행은 자동화하지 않습니다.
- 한국어 / 대만 번체 지원. 현장 로그는 PC에 보관하고 사용자가 JSON으로 내보냅니다.

사용 방법: 왼쪽 **LOT 테스트 기록 · 추천** → 모델·LOT 입력 → 기록 시작 → 평소처럼 테스트 → 결과 확인. 서로 다른 LOT 3개를 기록한 뒤 다음 LOT의 추천을 확인하세요.

검증: 자동 테스트 28개(원본 검사 22개 포함), Electron 10개 탭·번역·대화상자·LOT 기록 화면·로그 내보내기 통과. 실제 현장 경로와 데이터에 대한 추천 정확도는 현장에서 쌓인 기록으로 확인해야 합니다.

기존 사용자는 업데이트 다운로드 후 앱을 종료하면 적용됩니다. 기존 Python 백엔드 포함, 별도 Python 설치 불필요. 코드 서명 미적용.
