# DMT Analysis Studio 0.3.1

- 새 버전 감지 시 다운로드 진행 팝업을 표시하고, 다운로드 완료 후 **업데이트 및 재시작 / 更新並重新啟動**을 제공합니다.
- 버튼을 누르면 설치 후 앱이 자동으로 다시 실행됩니다. **나중에 / 稍後**를 선택할 수 있으며 업데이트 확인 버튼으로 팝업을 다시 열 수 있습니다.
- 팝업의 제목·설명·버튼·작업 중 안내·오류 문구는 현재 설정한 한국어 또는 대만 번체로 표시합니다.
- 분석 중에는 자동 팝업을 미루고, 작업 중 설치 요청을 차단합니다. 설치를 시작하면 새 분석 요청도 차단합니다.

검증: 업데이트 단위 테스트 4개와 기존 Python 테스트 28개, 실제 Electron에서 두 언어의 팝업·진행률·나중에·다시 열기·설치/재시작 호출 인자를 확인했습니다. 설치 테스트는 실제 PC 프로그램 교체 대신 NSIS의 무인 설치 및 재실행 인자 전달을 검증했습니다.

**최초 적용 안내:** 0.3.0 이하 버전에는 이 팝업이 없습니다. 이번 0.3.1은 기존 방식으로 업데이트 다운로드 후 앱을 종료하고 다시 실행하거나, 설치 파일을 직접 실행해 적용하세요. 0.3.1부터 다음 업데이트에 새 팝업을 사용할 수 있습니다.
