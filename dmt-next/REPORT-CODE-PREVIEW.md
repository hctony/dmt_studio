# 성적서 코드 미리보기 / 成績書代碼預覽

0.4.5부터 **수율 계산 → 1차 성적서 생성 옆의 코드 미리보기**에서 실제 Excel에 기록될 코드별 수량과 전체 Unit 대비 비율을 확인할 수 있습니다. Excel과 같은 변환 함수를 사용하므로 170은 OT06에 합산하고, 수량이 0인 코드는 표시하지 않습니다.

## 사용 방법

1. VRS/FVI/IVS 공정 TXT와 필요한 IVS JSON·BBT·최종 SKI를 입력하고 수율을 계산합니다.
2. **코드 미리보기**에서 UNKNOWN, 1111, SM03_DUMMY9999 또는 다른 코드를 선택합니다.
3. StripID·X/Y 행을 선택하면 계산 당시의 배정 공정·사유와 TXT, SKI, XML 원문을 비교할 수 있습니다. 좌표 목록은 200개씩 넘깁니다.
4. TXT/BBT 및 XML 선택 상자에서 다른 관련 파일을 고를 수 있습니다. `▶ L번호`는 선택 좌표와 일치하는 원문 행입니다. SKI는 해당 Strip의 다른 좌표도 함께 표시합니다.
5. IVS JSON에 원본 XML 경로가 있으면 바로 읽습니다. 경로가 없으면 **NAS XML 찾기**로 모델·LOT의 FC barcode와 StripID가 같은 XML 후보를 찾습니다. NAS 탐색은 시간이 걸릴 수 있으며 **조회 중지**로 중단할 수 있습니다.

UNKNOWN은 TXT의 빈 코드와 SKI 좌표에 대응하는 코드가 없는 경우를 구분합니다. 1111은 공정 TXT에서 직접 배정됐는지, IVS JSON을 통해 170에서 보정됐는지 표시합니다. SM03_DUMMY9999는 IVS Dummy 9999 판정 후 BBT를 제외한 좌표에 배정된 근거를 표시합니다. 기존 좌표 우선순위는 유지하며, 공정 TXT의 OT14가 BBT로도 재합산되던 성적서 오류를 수정했습니다.

## OT14 처리

0.4.6부터 **검사 대상 Strip의 RPT 좌표 전체**를 SKI 일치 여부·RPT 불량명·재작업 코드와 관계없이 OT14로 배정합니다. 같은 Strip·좌표는 한 번만 세며, 같은 좌표의 공정 불량은 제외합니다. 검사 대상 밖 Strip의 RPT 자료는 포함하지 않습니다. SKI에 빠진 RPT 좌표도 성적서와 NG 수량에 포함하며, SKI와의 차이는 검증 정보에 유지합니다. 공정 코드의 SKI 기준 배정과 양폐/Dummy 처리 우선순위는 유지합니다.

성적서 OT14 합계는 **BBT로 배정된 OT14 + 공정 TXT에서 별도로 배정된 OT14**입니다. 예를 들어 BBT 1개와 별도 공정 OT14 1개는 총 2개이며, BBT 수량 항목은 1개입니다. Dummy 9999에서도 BBT는 OT14를 유지하고 나머지 대상 좌표가 SM03_DUMMY9999가 됩니다. 미리보기의 배정 공정과 원문 RPT를 통해 두 출처를 구분할 수 있습니다.

## 비교 기준

- 계산 시점의 코드·선택된 TXT 내용·SKI/BBT 좌표·관련 IVS JSON 항목을 결과와 함께 보관합니다. SMART 중복 선택에서 탈락한 최신 파일을 계산 원본으로 오인하지 않도록 실제 선택된 파일을 따로 기록합니다.
- 원문 패널은 **지금 읽은 파일**입니다. TXT·SKI·IVS JSON 입력의 크기와 수정 시각을 계산 시점에 기록하며, 조회하는 TXT/SKI에 차이가 있으면 변경 표시를 합니다. 크기·수정 시각 일치는 파일 내용의 암호학적 동일성을 보증하지 않습니다. XML은 현재 원문의 Unit 항목 발췌이며 과거 파일을 복원하지 않습니다.
- Unit index는 계산에 사용한 X 폭으로 좌표를 환산한 **0 기준 값**입니다. 실제 IVS JSON의 `unit_idx`, XML의 `unit_idx`도 대조할 수 있습니다. 독립적인 설비 좌표 검증을 대신하지 않습니다.
- 원문 조회는 읽기 전용이며, B/C/D에서도 A PC를 통해 조회합니다. A PC에 허용된 데이터 폴더와 설정된 NAS 루트 권한을 적용합니다. 파일이 없거나 접근할 수 없으면 해당 패널에 오류를 표시하고 계산 시점 근거는 유지합니다.
- 원문은 관련 행 최대 200개, XML 최대 16 MB·관련 항목 최대 20개로 제한합니다. 선택을 빨리 바꿔도 이전 조회 결과가 새 좌표를 덮어쓰지 않습니다.
- 입력을 변경했다면 수율을 다시 계산해야 미리보기와 성적서를 생성할 수 있습니다. 기존 통합 TXT 계산에는 코드별 좌표 배정 기록이 없으므로, 이 경우 공정 TXT 입력으로 다시 계산하라는 안내를 표시합니다.
- 성적서 수량과 추적 좌표 수가 다르면 양쪽 수량을 표시해 집계 규칙을 확인할 수 있도록 합니다. 조회 기능에서 계산 결과를 자동 수정하지 않습니다.

## 繁體中文

先計算良率，再按「產生第一版成績書」旁的「代碼預覽」。選擇代碼與 Strip／Unit，即可比較計算當時的分配依據、TXT／BBT、SKI 和目前原始 XML。UNKNOWN 會區分空白代碼與找不到對應代碼；1111 會顯示 TXT 來源或 IVS JSON 修正來源。

沒有 XML 路徑時可按「尋找 NAS XML」，並可停止查詢。B/C/D 電腦由 A 電腦讀取原始資料；不會改寫原始檔案。切換語言只翻譯說明，原始路徑與檔案內容保持原樣。修改計算輸入後，請先重新計算良率。
