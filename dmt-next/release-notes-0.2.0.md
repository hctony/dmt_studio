# DMT Analysis Studio 0.2.0

기존 10개 탭의 작업 흐름을 Electron 안에 연결한 Windows x64 테스트 버전입니다. 별도의 원본 프로그램 창은 사용하지 않습니다.

- IVS·StripID·전체 XML, 게더링 집계·Strip 검색, 검사 통계, 수율, Strip 진단, LM Data, 테스트 탭.
- 이미지·그룹 다운로드, 재작업 날짜·중복 데이터 선택, 공정 일괄 추출, Excel, LM 실제 실행·백업까지 연결.
- 한국어·번체 중국어 즉시 전환, 최근 파일 경로와 입력 저장, 기존 모델 JSON 가져오기, NAS 연결 설정 화면.
- 원본 Python 백엔드와 Qt 런타임을 설치 파일에 포함하고 캐시·계산 로직을 재사용합니다.
- GitHub 자동 업데이트와 작업 중 종료 보호를 유지합니다.

검증: 자동 테스트 16개(원본 검사 22개 포함), 실제 Electron의 탭/번역/대화상자, 로컬 SFTP 대역의 스캔·3광원 다운로드, Excel 및 LM 백업. 실제 대만 NAS 데이터·대규모 작업은 현장에서 확인해 주세요.

0.1.1 사용자는 업데이트 확인 후 앱을 종료하면 적용됩니다. 최초 설치 시 왼쪽의 NAS 연결 설정과 모델 설정 가져오기를 사용하세요. 현장 비밀번호·데이터는 GitHub에 포함되지 않습니다. 코드 서명은 아직 적용되지 않았습니다.
