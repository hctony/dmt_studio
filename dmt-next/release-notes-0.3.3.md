# DMT Analysis Studio 0.3.3

0.3.2의 백엔드 복구 및 설치 보호에 업데이트 조회 캐시 재검증을 추가한 수정 버전입니다.

- 업데이트 확인은 앱을 종료하거나 설치를 시작하지 않습니다. 다운로드 완료 후 **업데이트 및 재시작**을 눌러야 설치합니다.
- 업데이트 조회 시 캐시를 재검증하여 이전 릴리스가 계속 표시되는 문제를 방지합니다.
- 백엔드가 완전히 종료된 뒤 설치를 시작하며, 앱 중복 실행과 현재 버전의 중복 설치를 막습니다.
- Qt/Shiboken 필수 파일 검사, 한국어/번체 오류 안내, **다시 연결**을 제공합니다. 백엔드가 실패해도 업데이트 확인과 앱 창은 유지됩니다.
- 실제 NSIS 설치 후 백엔드·10개 탭·LOT 초기화를 검증하고 그 설치 파일을 그대로 배포합니다.

검증: Python 테스트 28개, JavaScript 테스트 10개, 강제 백엔드 실패 후 재연결, 두 언어 업데이트 팝업, 업데이트 없음 상태의 창 유지. 실제 설치된 0.3.2에서도 10개 탭·LOT 연결과 업데이트 확인을 검증했습니다. 원래 보고된 종료 현상의 정확한 조건은 재현되지 않았지만, 설치/백엔드 경합 경로를 보완했습니다.

기존 설치에 오류가 있으면 0.3.3 설치 파일을 직접 실행하여 복구하세요. 사용자 설정과 현장 데이터는 유지됩니다.
