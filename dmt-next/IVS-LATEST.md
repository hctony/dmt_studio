# 0.4.10 Barcode별 마지막 IVS 작업 적용

IVS 수집 결과는 XML의 Strip Barcode별로 마지막 작업 하나만 반영합니다. 작업은 설비·Trial·Strip 폴더로 구분하며, 해당 작업의 XML 원본 수정 시각 중 최댓값을 비교합니다. Trial 번호, 폴더 이름, 설비 탐색 순서는 최신 작업 판정 기준으로 사용하지 않습니다.

예를 들어 동일 Barcode가 A 설비 Trial 99에서 SM03, 이후 B 설비 Trial 2에서 OT12, 마지막 C 설비 Trial 1에서 불량 0개라면 현재 결과는 불량 0개입니다. 과거 SM03·OT12·Dummy 9999는 현재 불량 수·이미지 목록·수율 보정에 다시 합치지 않습니다. 서로 다른 Barcode는 각자의 마지막 작업을 유지합니다.

같은 작업 폴더의 앞·뒷면 등 분할 XML은 함께 유지합니다. 같은 XML이 반복 탐색되면 현재 결과의 동일 기록은 중복 제거합니다. 같은 Trial 안에서도 Barcode가 다른 Strip 폴더에서 다시 검사되면 최신 폴더를 선택합니다. 기존 유효 Bundle의 FC-only 처리와 불량 없는 Strip의 전체 Unit 집계는 유지합니다.

JSON의 `records`, `strips`, `summary`는 현재 선택 결과입니다. 과거 불량 기록은 `history_records`, 전체 작업 시각·출처는 `strip_history`, 선택 결과·사유는 `latest_selection`으로 보존합니다. 수율 계산은 현재 작업의 IVS만 적용하고 과거 기록은 SKI 갱신·재작업 비교 근거로만 사용합니다. 불량 0개 결과도 JSON으로 저장할 수 있습니다.

기존 JSON에 작업 이력과 시각이 있으면 열 때 최신 결과로 변환하며, 과거 기록을 별도로 보존합니다. 작업 이력이 없는 구형 JSON은 시각을 추측해 최신 작업을 선택하지 않습니다.

현재 확인 가능한 시각은 XML 파일 수정 시각입니다. XML 내부의 실제 검사 시각을 확인한 것으로 표시하지 않습니다. 서로 다른 작업의 최종 시각이 같거나 시각이 없으면 한 작업만 임시 선택하고 확인 필요로 표시하며, 이력 검증을 완료 처리하지 않습니다. 최신 XML을 읽지 못한 작업의 Barcode가 FC로 확인되면 해당 작업을 미완료로 남기고 과거 불량을 최신 결과로 되살리지 않습니다. 수집·ITS 검증이 미완료인 성적서는 기존과 같이 차단합니다.

이 버전은 최신 이력 적용 규칙 변경입니다. 설비 병렬화, 분석 결과 캐시, Trial 인덱스 등 앞서 제안한 성능 최적화는 포함하지 않습니다. 전체 Trial 탐색은 유지합니다.

## 繁體中文

依 XML 的 Strip Barcode，僅將最後一次作業反映於目前結果。以設備／Trial／Strip 資料夾區分作業，比較 XML 原始檔修改時間；不使用 Trial 編號或搜尋順序推測最新作業。最新結果為零不良時，也會移除先前不良及 Dummy 9999。相同作業的正反面分割 XML 仍一起保留，不同 Barcode 各自保留其最新作業。

目前結果保存在 records／strips／summary，先前紀錄另存於 history_records，作業來源與時間保存在 strip_history，選擇依據保存在 latest_selection，供重工及 SKI 驗證使用。零不良結果也可儲存 JSON。時間相同、無法確認時間或最新 XML 讀取失敗時，顯示需確認的暫存結果，成績書仍受原有驗證限制。本版未加入先前提出的平行化或索引效能改善。
