# DMT Analysis Studio 0.3.2

백엔드 시작 오류와 업데이트 설치 경합을 방지하기 위한 수정입니다.

- 업데이트 확인과 일반 앱 종료에서는 설치를 시작하지 않습니다. 새 버전이 준비된 뒤 **업데이트 및 재시작**을 눌렀을 때만 설치합니다.
- 설치 전에 분석 백엔드가 완전히 종료될 때까지 기다립니다. 종료 실패 시 설치를 중단합니다.
- 앱 중복 실행을 막고, 현재 버전과 같은 캐시 업데이트는 설치하지 않습니다.
- Qt/Shiboken 필수 파일을 시작 전에 검사합니다. 백엔드 시작 실패가 발생해도 앱을 유지하고, 한국어/번체 안내와 **다시 연결** 버튼을 제공합니다.
- 시작 실패 상태에서 후속 요청마다 백엔드를 반복 실행하지 않습니다. 업데이트 확인은 계속 사용할 수 있습니다.
- 배포 검증에 실제 NSIS 설치 후 Qt 로딩·10개 탭·LOT 상태 조회를 추가했습니다. 검증한 설치 파일을 그대로 업로드합니다.

확인 범위: 현재 PC에 설치된 0.3.1의 필수 DLL은 존재했고, 격리 프로필에서 백엔드와 업데이트 없음 응답은 정상 확인했습니다. 보고된 종료 현상의 정확한 발생 조건은 재현되지 않았습니다. 위 변경은 확인된 설치/백엔드 수명 관리 경로를 보완한 것입니다.

자동 테스트: Python 28개와 업데이트/백엔드 JavaScript 10개. Electron에서 강제 백엔드 실패 후 업데이트 확인·재연결, 두 언어의 업데이트 팝업과 설치 호출을 확인했습니다.

설치 파일이 누락되거나 업데이트가 반복 실패하는 기존 설치본은 0.3.2 설치 파일을 실행하여 복구하세요. 사용자 데이터와 모델 설정은 유지됩니다.
