# Electron 기능 연결표 — 0.2.0

기존 Python/Qt의 화면 동작 및 계산 코드를 화면 없는 백엔드에서 실행한다. 사용자 화면은 Electron의 HTML 컨트롤이며 별도 원본 프로그램 창을 열지 않는다. Qt 런타임과 Python 백엔드는 설치 파일에 포함된다.

| 화면 | 연결된 원본 작업 |
|---|---|
| IVS 분석/조회 | LOT 자동 추론·목록, Trial 선택, 스캔, JSON 열기·저장, 불량/재작업/Dummy 필터, Strip 검색, 3광원 이미지, 그룹 선택 다운로드 |
| StripID 추출 | LOT/Trial 조회, Bundle·FC 분석, StripID 추출, JSON 저장 |
| 전체 XML Barcode | 재귀 스캔, 중복 위치, JSON 저장, StripID JSON 누락 비교 |
| 게더링 집계 | VRS/FVI/IVS 설정, 제외 코드·Strip, X-out 처리, 날짜 선택, 중복 선택·병합, 중지, 공정별 TXT 저장, 3공정 일괄 추출 |
| 게더링 Strip 검색 | 저장된 설비 경로 검색, 좌표·불량코드·원본 라인 표시 |
| 검사 통계 | 기간·설비 설정, 검사원 집계, 행 클릭 상세 창, 전체·상세 Excel 저장 |
| 수율 계산 | 기존/공정별 입력, 모델 설정, Dummy 9999, 공정 필터, 기본·성적서 결과, 불일치 필터, Strip JSON/BBT 진단, JSON·Excel 출력 |
| StripID 진단 | 누락, LOT/모델 조회, 좌표 검색, SKI 최종 검증, 상세 로그, 검증 JSON |
| LM Data | 검증 JSON, 미리보기, 실행 확인, SMK BK 이동, PMK 백업·재작성 |
| 테스트 | 원본 22개 검사, 전체 실행·실패 재실행, 선택 항목 상세 |

입력은 기존 QSettings와 모델 JSON을 사용하며 추가로 사용자 데이터 폴더의 gui-inputs.json에 보존한다. 파일 선택의 최근 경로도 보존한다. 모델 JSON 가져오기는 실행 중인 백엔드를 유지하며 반영한다. 파싱 및 파일 목록 캐시는 백엔드가 종료될 때까지 유지된다. 업데이트 시 사용자 설정 파일은 설치 파일로 덮어쓰지 않는다.

한국어·번체 중국어는 재시작 없이 전환한다. 원본 파일명, 불량 코드, 예외 메시지 등 데이터 자체는 원문을 포함할 수 있다.

## 검증 범위

- 자동 테스트 16개 통과. 이 중 원본 테스트 레지스트리의 22개 검사도 실행한다.
- 수율 계산과 Excel 생성, IVS JSON/다운로드 선택, LM 취소·실행·백업, 날짜/중복 대화상자, 3공정 일괄 추출, SKI 검증 JSON, 입력 보존, 페이지 이동을 확인했다.
- 로컬 SFTP 대역으로 원본 IVS/StripID/XML 스캔과 세 광원 이미지 다운로드를 실행했다. 실제 NAS 통신 검증과는 구분한다.
- 실제 Electron에서 10개 탭, 번체 전환, 검증 대화상자 왕복을 확인하고 화면을 캡처해 점검했다.
- 대만 NAS 접근 권한·실제 파일 형식의 모든 변형·대규모 데이터 성능은 현장 테스트 대상이다.
