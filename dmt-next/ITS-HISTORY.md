# ITS 최신 이력 검증 (0.4.7)

## 사용 순서

업데이트 후 **IVS LOT 전체 수집 → VRS/IVS/FVI 게더링 → 수율 계산**을 다시 실행합니다. 새 IVS JSON에 Strip별 설비·Trial·원본 XML 경로·원본 수정 시각을 기록합니다. TXT 파일명의 검사원 번호는 Trial 번호로 사용하지 않습니다. 기존 JSON에는 이 시각 이력이 없으므로 새 자동 판정에는 재수집이 필요합니다. 기존 형식의 수동 검수 흐름은 호환을 유지합니다.

IVS 유효 Bundle의 FC-only 정상 Strip도 설비/Trial 이력을 기록합니다. 파싱 실패 등 불완전한 수집 이력, 설비/Trial의 시각을 구분할 수 없는 이력은 자동 확정하지 않습니다. 검사 범위 안에 이력 없는 Strip이 남으면 성적서 생성을 차단합니다.

## 선택과 결합

- Strip마다 XML 이력에서 최신 설비·Trial을 찾습니다. Trial 이름의 숫자 크기가 아닌 **원본 파일 시각**을 사용하며, 같은 최신 시각에 다른 설비·Trial이 있으면 확정하지 않습니다.
- 최신 Trial 시작 전 TXT는 새 집계에 다시 합치지 않습니다. 같은 Strip의 최신 빈 결과도 이전 불량 결과를 대체할 수 있습니다.
- 같은 검증된 Trial 안의 부분 TXT는 합집합+RPT가 SKI 좌표에 정확히 일치하고 SKI 시각이 해당 자료보다 새로울 때만 결합합니다. 이전 Trial들을 합쳐 SKI에 맞추지 않습니다. 최신 빈 결과에 과거 불량을 다시 합치지 않습니다.
- 날짜가 여러 개여도 서로 중복 Strip이 없으면 날짜 선택 없이 결합합니다. XML 이력이 없는 날짜 간 중복 Strip은 기존 검수로 남습니다.
- 자동 수율 연결용 TXT에는 `.txt.its.json` 출처 파일을 함께 저장합니다. Strip별 원본 시각·출처를 보존하고 TXT 내용 해시를 확인하므로, 내보내기 시각을 검사 시각으로 오인하지 않습니다. 출처 파일과 내용이 맞지 않으면 자동으로 신뢰하지 않습니다.

## 9998과 좌표 비교

IVS 9998은 확정 불량에 넣지 않습니다. 해당 Strip의 IVS 이후 VRS 결과가 있고, 같은 좌표가 VRS에서 다른 불량으로 남으면 그 코드를 반영합니다. VRS에서 좌표가 사라지면 가성으로 취급합니다. 해당 Strip의 VRS 결과 자체가 없거나 9998로 남아 있으면 재판정 완료를 확정하지 않습니다.

확정 IVS + VRS + FVI + RPT의 **Strip/X/Y 고유 좌표 합집합**을 SKI와 비교합니다. 코드·면·중복 라인이 달라도 같은 Unit 좌표를 여러 번 더하지 않습니다. RPT는 검사 대상 Strip의 이전 공정 불량으로 항상 포함합니다.

| 상태 | 처리 |
|---|---|
| 최신 이력·검사 범위가 확인되고 좌표 차이 없음 | 자동 PASS |
| SKI에만 좌표가 있음 | 소스 누락으로 차단 |
| 취합 자료에만 좌표가 있음 | SKI 갱신 필요, 갱신 후 재계산 |
| 같은 수량이지만 양쪽 좌표가 다름 | 좌표 불일치로 차단 |
| 새 Trial에서 폐기된 것으로 확인된 옛 IVS 좌표만 오래된 SKI에 남음 | 소스 누락으로 단정하지 않고 SKI 갱신 유도 |
| 이력·VRS 재판정·입력 안정성 미확인 | 자동 PASS 금지 |

검증 미완료 시 경고와 Strip·Trial·차이 좌표를 표시하고 성적서 생성을 차단합니다. 코드 미리보기와 JSON 결과는 근거 확인에 사용할 수 있습니다. 소스 또는 SKI를 보완한 뒤 **수율 계산**을 다시 눌러 검증합니다. 계산 도중 입력 파일이 변경돼도 자동 PASS를 중단합니다. 원본 TXT·XML·SKI를 수정하거나 삭제하지 않습니다.

## 검색과 캐시

게더링 검색은 최근 30일 이내로 제한하며 7일 범위도 선택할 수 있습니다. 이전에 저장한 전체 기간/31일 설정은 30일로 전환됩니다. 기존 생성·수정 시각 기반 검색 및 LOT 공통 디스크 캐시를 사용하며, 바뀐 TXT는 다시 읽고 변경되지 않은 TXT와 다른 LOT의 내용은 캐시/헤더 인덱스로 재사용·건너뜁니다. 폴더 메타데이터는 새 파일 발견을 위해 다시 열람합니다.

## 시각 근거와 검증 범위

현재 시각 근거는 XML/TXT/SKI의 **파일 수정 시각**입니다. 실제 검사 장비 내부의 검사 시각 필드를 파싱했다는 뜻이 아닙니다. 원본 복사로 시각이 바뀌었거나 장비 시계가 다른 경우에는 원본 이력과 대조해야 합니다. 대만 실물 NAS에서는 아직 검증하지 않았으며, 검사원 번호/숫자 Trial/내보내기 시각으로 임의 보정하지 않습니다.

테스트는 9998 가성 판정, VRS 미확인/9998 잔존, FVI 추가 후 SKI 갱신, 같은 수량의 좌표 불일치, 오래된 Trial 제외, 최신 빈 결과, 동일 Trial 부분 결합, 출처 해시 불일치 등을 포함합니다.

## 繁體中文

更新後請重新執行完整 IVS 收集，建立每片 Strip 的設備、Trial、原始 XML 路徑與修改時間，再執行整合統計及良率計算。TXT 檔名的檢查員編號不作為 Trial。

IVS 9998 待 VRS 複判；有較晚的同 Strip VRS 結果時，該座標保留不良碼則計入，座標消失則視為誤判。缺少該 Strip 的 VRS 結果或仍為 9998 時不自動確認。最新 IVS/VRS/FVI 與 RPT 的唯一座標聯集須與 SKI 一致；原始資料缺漏、SKI 待更新或歷程未確認時暫停產生成績書，修正後重新計算。
